# VAD-Promptless 教學指南

傳統：`Prompt → Practice → Output`

本方法：`Use → Understand → Compose → Orchestrate → Design → Govern`

## USE
選 Skill、放資料、判斷成果，不要求先背 Prompt 框架。

## UNDERSTAND
拆開 `TASK / INPUT / STYLE / PROCESS / OUTPUT / QA`，再解釋 Prompt、Context、Rules。

## COMPOSE
將多個 Skill 串成 Workflow。

## ORCHESTRATE
介紹 Agent：什麼時候要自己決定下一步。

## DESIGN
使用 VAD 十欄設計 Agent。

## GOVERN
QA、Evaluation、Human Review、權限、版本、稽核、MCP / A2A 邊界。

## 課堂實驗
- A：Prompt-first
- B：Promptless Skill
- C：Visual Skill Card
- D：Promptless Agent + VAD

比較完成時間、成功率、修改次數、認知負荷與成果品質。
