# Promptless Skill × VAD 教學指南

## 教學核心

傳統常見路徑：

```text
Prompt → Practice → Output
```

本方法建議：

```text
Use → Understand → Compose → Orchestrate → Design → Govern
```

## 第一層：USE

目標：第一次使用 AI 的學員也能完成工作。

教：
- 需求辨識
- 選 Skill
- 放資料
- 判斷成果

不要求先背 Prompt 框架。

## 第二層：UNDERSTAND

拆開 Skill，讓學員看到：

```text
TASK / INPUT / STYLE / PROCESS / OUTPUT / QA
```

此時再解釋 Prompt、Context、Rules 的作用。

## 第三層：COMPOSE

將兩個以上 Skill 串成 Workflow。

## 第四層：ORCHESTRATE

介紹 Agent：什麼時候要自己決定下一步。

## 第五層：DESIGN

使用 VAD 十欄設計 Agent。

## 第六層：GOVERN

教：
- QA
- Evaluation
- Human Review
- 權限
- 版本
- 稽核
- MCP / A2A 邊界

## 課堂實驗

同一任務分四組：

- A：Prompt-first
- B：Promptless Skill
- C：Visual Skill Card
- D：Promptless Agent + VAD

比較完成時間、成功率、修改次數、認知負荷與成果品質。
